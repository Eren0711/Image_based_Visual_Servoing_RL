# Documentation status

`PROJECT.md` and `configs/canonical/fixed_camera_intercept_v1.yaml` are the
only normative sources for current project scope.

- `current/phase1_completion.md` records the completed consolidation and its
  acceptance evidence.
- `current/legacy_artifact_inventory.{md,json}` is the reproducible read-only
  checkpoint/provenance audit.
- `current/repository_structure.md` defines where new files belong.

- `legacy/studies/hardnet_*.md` and matching files under `legacy/raw/` are
  preliminary historical evidence. They are not publication-grade or
  canonical MVP results.
- `legacy/studies/sixdof_target_claimA.md` and
  `legacy/studies/sixdof_target_claimB.md` are exploratory equal-capability
  studies outside canonical v1.
- `archive/implementation_plan.md` is the historical development log.
- `report/*.tex` contains historical draft manuscripts, not current claims.
- `references/geometric_analysis*` is exploratory analysis whose impossibility
  claims are not established and must not be used as project conclusions.

Do not copy a number or claim from these files into a new report without tying
it to a reproducible run, resolved config and episode-level result record.

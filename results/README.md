# Results Directory

This directory contains derived figures, exploratory JSON outputs, and written
interpretations from historical studies. These files are useful research notes,
but they are not automatically canonical or publication-grade evidence.

For a result to support a current claim, it should be reproducible from a named
evaluation suite, a checkpoint hash, a resolved configuration, a run manifest,
and machine-readable per-episode records. Existing material that lacks those
items remains legacy evidence and should be labeled accordingly.

Large training artifacts remain under `logs/`; their read-only inventory is in
`docs/current/legacy_artifact_inventory.md`.
